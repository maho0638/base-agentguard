# Source Review

This project was shaped around official OpenAI and Base documentation.

## OpenAI Codex for Open Source

- Program page: https://openai.com/form/codex-for-oss/
- Developer overview: https://developers.openai.com/codex/codex-for-oss
- Program terms: https://developers.openai.com/codex/codex-for-oss-terms

Key requirements reflected in this repo:

- public GitHub repository
- active primary or core maintainer
- clear evidence of maintenance workflows
- issue triage, PR review, release management, security, and code quality
- API-credit use tied to maintainer automation and core open-source work

Key requirements reflected in this repo:

- Base mainnet and Base Sepolia network awareness
- Base MCP onboarding before wallet actions
- `send_calls` mapping for prepared calldata
- x402 max-payment review and approval flow
- Builder Code attribution plan
- Base Sepolia proof contract
- clear demo, README, docs, and impact tracking
- trust posture: verified contracts, no custody, no seed phrases, no hidden execution
